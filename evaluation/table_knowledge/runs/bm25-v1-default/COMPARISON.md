# BM25 预处理效果对照

相同72张表、247条知识、2555条训练问题及270对答案；仅替换文本相似度通道。显式引用、字段匹配、字典值和外键值规则保持一致。当前默认算法仍为TF-IDF。

BM25参数k1=1.5、b=0.75，使用正IDF，查询特征去重，以查询IDF理论上界归一化（包含未见词惩罚）。Schema描述/训练question为查询，知识全文及分句为文档；取最高匹配分。其分数不是概率，不能将相同数值阈值理解成完全相同置信度。

## 使用

```bash
T2Q_PREPROCESSED_DIR=data/preprocessed/bm25-v1 PYTHONPATH=src .venv/bin/python -B -m text2query.cli build-catalog --association-method bm25 --association-threshold 0.30 --bm25-k1 1.5 --bm25-b 0.75
.venv/bin/python -B evaluation/table_knowledge/evaluate_preprocessing.py --method bm25 --output-dir /tmp/bm25-eval-new
```

示例通过环境变量将BM25目录写入data/preprocessed/bm25-v1；默认TF-IDF目录保持原样。

`tables.json` 为BM25逐表结果，`association_audit.json` 为得分证据，`report.json` 为逐表差异、阈值扫描及来源哈希，`comparison.json` 为对照统计。

本轮只比较了默认k1、b与所列阈值，没有穷举BM25参数。参数/阈值选择和结果解读使用当前答案集，属于同集开发评估，不能作为未见数据的泛化成绩。BM25评分使用原始文本，不读取答案，也不调用LLM。
